# Todo List

A simple Todo List application built using React.js. This project allows users to add, complete, and delete tasks while keeping track of their daily activities.

## Live Demo

https://kanika-0613.github.io/Todo-List/

## About the Project

I built this project while learning React.js to understand how components, state, and user interactions work in a React application.

The application provides a simple way to manage tasks. Users can add new tasks, mark tasks as completed, and remove tasks when they are no longer needed.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Prevents adding empty tasks
- Simple and clean user interface
- Responsive design
- Interactive task management

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite
- Git
- GitHub

## How It Works

The application uses React state to store and manage the list of tasks.

When a user enters a task and clicks the add button, the task is added to the list. Users can then mark tasks as completed or delete them from the list.
