React Todo List 📝
This is a simple Todo List project I made while learning React.js.
It helps users add and manage their daily tasks in an easy way.

Features -
Add a new task
Prevent empty tasks
Prevent duplicate tasks
Mark tasks as completed
Delete tasks
Simple and clean UI

Technologies Used -
React.js
JavaScript
HTML
CSS
Vite

What I Learned -
While making this project, I practiced:
React components
useState
Event handling
Forms and input fields
.map() method
Working with arrays and objects
Conditional rendering

About -
